About MedRAG v2.0 Institutional

Architecture, Safety Protocols & Regulatory Invariants

MedRAG v2.0 is an institutional-grade clinical intelligence platform engineered for zero diagnostic hallucinations. Pure Hexagonal domain models are decoupled from cloud vector infrastructure, enforcing deterministic sentence-level contradiction redaction and zero-loss patient timeline fusion.

Deterministic NLI Safety

Every generated clinical sentence undergoes atomic tokenization and DeBERTa-v3 cross-encoder entailment scoring. Contradiction probability P(Contra) ≥ 0.60 triggers automatic redaction tombstones.

In-Process Hybrid Retrieval

Combines Apache Arrow columnar storage (LanceDB) with Tantivy BM25 lexical search via Reciprocal Rank Fusion (RRF, k=60), delivering sub-10ms retrieval without cloud egress costs.

Dual-Track Ingestion

Zero-loss ingestion of HL7 FHIR R4 JSON bundles into chronological encounter timelines paired with layout-aware PDF pathology table parsing preserving abnormal flags and LOINC codes.

Institutional Governance

Compound tenant isolation (tenant_id / clinic_id / patient_id), automated HIPAA Safe Harbor de-identification, and Four-Eyes Chief Medical Officer override review backed by immutable audit trails.
